## Assignments Overview

### Assignment 1 – Requirement Analysis & User Story Writing

**Objective:** Analyze requirements for an Online Book Store and write user stories.

**Tasks Completed:**

* Requirement refinement
* Functional requirements documentation
* Non-functional requirements identification
* User stories in Gherkin format
* Acceptance criteria writing

**Deliverable:** PDF submission

---

### Assignment 2 – Test Plan & Test Case Writing

**Objective:** Create test plans and test cases using Testworthy.

**Tasks Completed:**

* Test plan creation
* Test case writing
* Test suite management
* Test execution
* Report generation
* Test classification (Smoke, Regression, Negative, Security, Automation Ready)

**Tools Used:**

* Testworthy

---

### Assignment 3 – Bug Reporting

**Objective:** Identify and report bugs on sample websites.

**Tasks Completed:**

* Functional bug reporting
* UI bug reporting
* Release notes documentation
* Defect logging in Excel

**Tools Used:**

* Microsoft Excel

---

### Assignment 4 – API Testing with Postman

**Objective:** Perform API testing using Postman collections.

**Tasks Completed:**

* GET, POST, PUT, PATCH, DELETE requests
* Base URL variables
* Random request body generation
* JSON response parsing
* Chai assertions
* Pre-request scripts
* Test scripts
* API chaining using variables

**Tools Used:**

* Postman

**APIs Used:**

* RESTful API
* Simple Books API
* REST Countries API

---

### Assignment 5 – API Testing with JMeter

**Objective:** Create API test plans in JMeter.

**Tasks Planned:**

* CRUD API workflows
* CSV data-driven testing
* Thread groups, samplers, listeners
* Response validations

**Tools Used:**

* Apache JMeter

---

### Assignment 6 – Cypress Automation

**Objective:** Automate UI testing for SauceDemo.

**Tasks Planned:**

* Login success testing

* Cypress

### Assignment 7 – Selenium / Playwright Automation
